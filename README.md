# HTML 小游戏

无需安装依赖，用浏览器直接打开 HTML 文件即可游玩。

## 游戏

- [贪吃蛇](index.html)：方向键或 WASD 移动，空格暂停；支持手机滑动和方向按钮、三档速度及最高分保存。
- [水果连连看](lianliankan.html)：8 × 8 棋盘，180 秒限时；相同水果最多两次转弯连接消除，支持提示、洗牌、自动无解恢复及最快通关记录。

## 测试

安装 Node.js 后运行：

```sh
node --test tests/lianliankan.test.cjs
```

测试覆盖连线规则、随机路径校验、计分、暂停、洗牌、超时和完整通关流程。
